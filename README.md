# Naruto-Pixel-burst

A simple 2D game featuring Naruto-themed sprites and music. Built using C++, SFML 2.5, and Qt 5.14 for the user interface.

## Description
This game is my first attempt at creating a 2D game using Naruto's sprites and songs. It showcases basic game mechanics and is built with C++ for the core logic, SFML 2.5 for graphics and audio, and Qt 5.14 for the menu system.

## Build Instructions
1. Install the required dependencies:
   - SFML 2.5
   - Qt 5.14
2. Open the project in Qt Creator or use CMake to generate build files.
3. Compile and run the executable (Naruto.exe).
